Question Number: 1
Problem Title: Reverse a string
Problem Description:
Given a string, output its reverse.

Approach / Explanation:
1) Use two pointers from both ends.
2) Swap characters while left < right.
3) Move pointers inward after each swap.
4) This reverses in place.
5) Linear time and constant space.
6) Works for all ASCII characters.
7) Output the reversed string.

Brute Force Note:
Creating a new string is fine but uses extra space.

C++ Code:
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    string s; if (!(cin >> s)) return 0;
    int l = 0, r = (int)s.size() - 1;
    while (l < r) swap(s[l++], s[r--]);
    cout << s;
    return 0;
}

Time Complexity: O(n)
Space Complexity: O(1)

Question Number: 4
Problem Title: Check if two strings are anagrams
Problem Description:
Given two strings, determine if they are anagrams.

Approach / Explanation:
1) If lengths differ, not anagrams.
2) Count frequency of characters in the first string.
3) Subtract frequency for the second string.
4) If any count is non-zero, not an anagram.
5) Works for ASCII strings.
6) Linear time.
7) Output 1 if anagrams, else 0.

Brute Force Note:
Sorting both strings is O(n log n).

C++ Code:
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    string a, b; if (!(cin >> a >> b)) return 0;
    if (a.size() != b.size()) { cout << 0; return 0; }
    vector<int> freq(256, 0);
    for (char c : a) freq[(unsigned char)c]++;
    for (char c : b) freq[(unsigned char)c]--;
    for (int x : freq) if (x != 0) { cout << 0; return 0; }
    cout << 1;
    return 0;
}

Time Complexity: O(n)
Space Complexity: O(1)

Question Number: 23
Problem Title: Longest Common Substring
Problem Description:
Given two strings, find the length of their longest common substring.

Approach / Explanation:
1) Use dp[i][j] as length of common suffix ending at i-1 and j-1.
2) If chars match, dp[i][j]=dp[i-1][j-1]+1.
3) Else dp[i][j]=0 because substring must be contiguous.
4) Track the maximum value.
5) Fill the table row by row.
6) O(n*m) time.
7) Output the maximum length.

Brute Force Note:
Checking all substrings is O(n^3).

C++ Code:
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    string a, b; if (!(cin >> a >> b)) return 0;
    int n = a.size(), m = b.size();
    vector<vector<int>> dp(n + 1, vector<int>(m + 1, 0));
    int best = 0;
    for (int i = 1; i <= n; ++i) {
        for (int j = 1; j <= m; ++j) {
            if (a[i-1] == b[j-1]) {
                dp[i][j] = dp[i-1][j-1] + 1;
                best = max(best, dp[i][j]);
            }
        }
    }
    cout << best;
    return 0;
}

Time Complexity: O(n*m)
Space Complexity: O(n*m)

Question Number: 15
Problem Title: Check if one string is a rotation of another
Problem Description:
Given two strings, determine if one is a rotation of the other.

Approach / Explanation:
1) If lengths differ, not a rotation.
2) Concatenate the first string with itself.
3) Check if the second string is a substring of the concatenation.
4) If found, it is a rotation.
5) Use string find or KMP.
6) O(n) average time for find.
7) Output 1 if rotation, else 0.

Brute Force Note:
Checking all rotations explicitly is O(n^2).

C++ Code:
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    string a, b; if (!(cin >> a >> b)) return 0;
    if (a.size() != b.size()) { cout << 0; return 0; }
    string c = a + a;
    cout << (c.find(b) != string::npos ? 1 : 0);
    return 0;
}

Time Complexity: O(n)
Space Complexity: O(n)

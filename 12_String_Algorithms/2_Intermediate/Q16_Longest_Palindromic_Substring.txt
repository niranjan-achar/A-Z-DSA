Question Number: 16
Problem Title: Longest Palindromic Substring
Problem Description:
Given a string, find the longest palindromic substring.

Approach / Explanation:
1) Expand around each center (odd and even).
2) Track the longest length found.
3) For each center, expand while characters match.
4) Update best start and length.
5) This is O(n^2) time and O(1) space.
6) Works for all strings.
7) Output the longest substring.

Brute Force Note:
Checking all substrings for palindrome is O(n^3).

C++ Code:
#include <bits/stdc++.h>
using namespace std;

pair<int,int> expand(const string& s, int l, int r) {
    while (l >= 0 && r < (int)s.size() && s[l] == s[r]) { --l; ++r; }
    return {l + 1, r - l - 1};
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    string s; if (!(cin >> s)) return 0;
    int bestLen = 0, bestStart = 0;
    for (int i = 0; i < (int)s.size(); ++i) {
        auto [s1, l1] = expand(s, i, i);
        if (l1 > bestLen) { bestLen = l1; bestStart = s1; }
        auto [s2, l2] = expand(s, i, i + 1);
        if (l2 > bestLen) { bestLen = l2; bestStart = s2; }
    }
    cout << s.substr(bestStart, bestLen);
    return 0;
}

Time Complexity: O(n^2)
Space Complexity: O(1)

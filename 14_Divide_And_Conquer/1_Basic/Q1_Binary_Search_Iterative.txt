Problem 1: Binary Search (Iterative)

Description:
Implement binary search to find a target element in a sorted array. Return the index of the element if found, otherwise return -1.

Approach:
Use two pointers (left and right) to maintain the search space. Calculate mid and compare with target. Narrow down the search space accordingly.

Brute Force Note:
Linear search: O(n) time - iterate through entire array.

C++ Code:
```cpp
#include <iostream>
#include <vector>
using namespace std;

int binarySearch(vector<int>& arr, int target) {
    int left = 0, right = arr.size() - 1;
    
    while (left <= right) {
        int mid = left + (right - left) / 2;
        
        if (arr[mid] == target)
            return mid;
        else if (arr[mid] < target)
            left = mid + 1;
        else
            right = mid - 1;
    }
    
    return -1;  // Not found
}

int main() {
    vector<int> arr = {1, 3, 5, 7, 9, 11, 13};
    int target = 7;
    
    cout << "Index: " << binarySearch(arr, target) << endl;
    
    return 0;
}
```

Time Complexity: O(log n) - Binary search reduces search space by half each iteration
Space Complexity: O(1) - Only uses constant extra space

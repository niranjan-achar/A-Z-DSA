Problem 6: Find Peak Element

Description:
Find a peak element in an array. A peak is an element greater than its neighbors. Array boundaries can be compared with -infinity.

Approach:
Use binary search. If mid element is less than right neighbor, peak must be on right. Otherwise check left.

Brute Force Note:
Linear scan: O(n) time.

C++ Code:
```cpp
#include <iostream>
#include <vector>
using namespace std;

int findPeak(vector<int>& arr) {
    int left = 0, right = arr.size() - 1;
    
    while (left < right) {
        int mid = left + (right - left) / 2;
        
        if (arr[mid] > arr[mid + 1])
            right = mid;
        else
            left = mid + 1;
    }
    
    return left;
}

int main() {
    vector<int> arr = {1, 3, 20, 4, 1, 0};
    
    cout << "Peak index: " << findPeak(arr) << endl;
    cout << "Peak value: " << arr[findPeak(arr)] << endl;
    
    return 0;
}
```

Time Complexity: O(log n) - Binary search
Space Complexity: O(1) - Constant space

Problem 15: Strassen's Matrix Multiplication

Description:
Multiply two n×n matrices using Strassen's algorithm (divide and conquer approach).

Approach:
Divide matrices into quadrants. Use 7 multiplications instead of 8 to reduce complexity.

Brute Force Note:
Standard matrix multiplication: O(n³) time.

C++ Code:
```cpp
#include <iostream>
#include <vector>
using namespace std;

typedef vector<vector<int>> Matrix;

Matrix addMatrices(const Matrix& a, const Matrix& b, int size) {
    Matrix result(size, vector<int>(size));
    for (int i = 0; i < size; i++) {
        for (int j = 0; j < size; j++) {
            result[i][j] = a[i][j] + b[i][j];
        }
    }
    return result;
}

Matrix subtractMatrices(const Matrix& a, const Matrix& b, int size) {
    Matrix result(size, vector<int>(size));
    for (int i = 0; i < size; i++) {
        for (int j = 0; j < size; j++) {
            result[i][j] = a[i][j] - b[i][j];
        }
    }
    return result;
}
```

Question Number: 27
Problem Title: Check if number is a Kaprekar number
Problem Description:
A Kaprekar number can be split from its square into two parts that sum to the original number.

Approach / Explanation:
1) Compute n^2.
2) Split the decimal string into left and right parts.
3) Convert both parts to integers, treating empty part as 0.
4) If left + right equals n, it is Kaprekar.
5) Try all valid split positions.
6) O(d^2) due to substring checks.
7) Output 1 if Kaprekar, else 0.

Brute Force Note:
Trying all splits is already the standard approach.

C++ Code:
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    long long n; if (!(cin >> n) || n < 0) return 0;
    long long sq = n * n;
    string s = to_string(sq);
    for (int i = 1; i <= (int)s.size(); ++i) {
        long long left = stoll(s.substr(0, i));
        long long right = (i == (int)s.size() ? 0 : stoll(s.substr(i)));
        if (left + right == n) { cout << 1; return 0; }
    }
    cout << 0;
    return 0;
}

Time Complexity: O(d^2)
Space Complexity: O(d)

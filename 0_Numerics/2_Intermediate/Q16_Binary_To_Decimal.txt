Question Number: 16
Problem Title: Convert binary to decimal
Problem Description:
Given a binary string, convert it to decimal.

Approach / Explanation:
1) Traverse the binary string left to right.
2) Multiply current result by 2.
3) Add the current bit.
4) Repeat for all digits.
5) This is equivalent to base-2 parsing.
6) Linear time.
7) Output the decimal value.

Brute Force Note:
Repeated power calculation is slower.

C++ Code:
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    string s; if (!(cin >> s)) return 0;
    long long val = 0;
    for (char c : s) val = val * 2 + (c - '0');
    cout << val;
    return 0;
}

Time Complexity: O(n)
Space Complexity: O(1)

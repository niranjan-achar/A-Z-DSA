Question Number: 18
Problem Title: Find HCF using Euclidean algorithm
Problem Description:
Given two integers, compute their HCF/GCD using Euclid's method.

Approach / Explanation:
1) Repeatedly replace (a, b) with (b, a % b).
2) When b becomes 0, a is the HCF.
3) This is Euclidean algorithm.
4) Efficient for large inputs.
5) O(log min(a,b)) time.
6) Output the HCF.
7) Same as gcd.

Brute Force Note:
Checking all divisors is slower.

C++ Code:
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    long long a, b; if (!(cin >> a >> b)) return 0;
    a = llabs(a); b = llabs(b);
    while (b != 0) { long long t = a % b; a = b; b = t; }
    cout << a;
    return 0;
}

Time Complexity: O(log min(a,b))
Space Complexity: O(1)

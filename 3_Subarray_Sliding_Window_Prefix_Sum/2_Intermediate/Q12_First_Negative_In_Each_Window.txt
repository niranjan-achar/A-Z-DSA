Question Number: 12
Problem Title: First negative integer in every window of size k
Problem Description:
Given an array and k, print the first negative number in each window, or 0 if none.

Approach / Explanation:
1) Use a deque to store indices of negative elements.
2) For each new element, add its index if it is negative.
3) Remove indices that fall out of the current window.
4) The front of the deque is the first negative for that window.
5) If deque is empty, answer is 0.
6) Linear time using deque.
7) Output one value per window.

Brute Force Note:
Checking each window linearly costs O(nk).

C++ Code:
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, k; if (!(cin >> n) || n <= 0) return 0;
    vector<long long> a(n);
    for (int i = 0; i < n; ++i) cin >> a[i];
    cin >> k;
    if (k <= 0 || k > n) return 0;

    deque<int> dq;
    for (int i = 0; i < n; ++i) {
        if (a[i] < 0) dq.push_back(i);
        if (!dq.empty() && dq.front() <= i - k) dq.pop_front();
        if (i >= k - 1) {
            if (i > k - 1) cout << " ";
            cout << (dq.empty() ? 0 : a[dq.front()]);
        }
    }

    return 0;
}

Time Complexity: O(n)
Space Complexity: O(k)

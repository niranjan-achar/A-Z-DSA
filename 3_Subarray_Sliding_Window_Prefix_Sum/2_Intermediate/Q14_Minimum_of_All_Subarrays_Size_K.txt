Question Number: 14
Problem Title: Minimum of all subarrays of size k
Problem Description:
Given an array and k, output the minimum in each window of size k.

Approach / Explanation:
1) Use a deque of indices with increasing values.
2) Remove indices that fall out of the window.
3) Remove larger values from the back before adding new index.
4) The front holds the minimum of the current window.
5) Each element is processed once.
6) This yields linear time.
7) Output min for each window.

Brute Force Note:
Scanning each window costs O(nk).

C++ Code:
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, k; if (!(cin >> n) || n <= 0) return 0;
    vector<long long> a(n);
    for (int i = 0; i < n; ++i) cin >> a[i];
    cin >> k;
    if (k <= 0 || k > n) return 0;

    deque<int> dq;
    for (int i = 0; i < n; ++i) {
        while (!dq.empty() && dq.front() <= i - k) dq.pop_front();
        while (!dq.empty() && a[dq.back()] >= a[i]) dq.pop_back();
        dq.push_back(i);
        if (i >= k - 1) {
            if (i > k - 1) cout << " ";
            cout << a[dq.front()];
        }
    }

    return 0;
}

Time Complexity: O(n)
Space Complexity: O(k)

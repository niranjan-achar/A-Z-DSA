Question Number: 16
Problem Title: Longest substring with no repeating characters
Problem Description:
Given a string, find the length of the longest substring without repeating characters.

Approach / Explanation:
1) Use sliding window with last seen positions.
2) If a repeat appears inside the window, move left to last seen + 1.
3) Update the maximum window length each step.
4) This keeps the window valid and minimal.
5) Single pass yields linear time.
6) Works for ASCII characters.
7) Output the maximum length.

Brute Force Note:
Checking all substrings costs O(n^2).

C++ Code:
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    string s; if (!getline(cin >> ws, s)) return 0;
    vector<int> last(256, -1);
    int left = 0, best = 0;
    for (int i = 0; i < (int)s.size(); ++i) {
        unsigned char c = s[i];
        if (last[c] >= left) left = last[c] + 1;
        last[c] = i;
        best = max(best, i - left + 1);
    }

    cout << best;
    return 0;
}

Time Complexity: O(n)
Space Complexity: O(1)

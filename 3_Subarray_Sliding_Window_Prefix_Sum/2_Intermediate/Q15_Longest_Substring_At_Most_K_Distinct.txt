Question Number: 15
Problem Title: Longest substring with at most k distinct characters
Problem Description:
Given a string and k, find the length of the longest substring with at most k distinct characters.

Approach / Explanation:
1) Use sliding window with a frequency map.
2) Expand right pointer and increment char count.
3) While distinct count exceeds k, shrink from left.
4) Track the maximum window length.
5) This maintains validity of the window.
6) Linear time with bounded alphabet.
7) Output the maximum length.

Brute Force Note:
Checking all substrings costs O(n^2).

C++ Code:
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    string s; if (!getline(cin >> ws, s)) return 0;
    int k; if (!(cin >> k)) return 0;

    unordered_map<char, int> freq;
    int left = 0, best = 0;
    for (int right = 0; right < (int)s.size(); ++right) {
        ++freq[s[right]];
        while ((int)freq.size() > k) {
            char c = s[left++];
            if (--freq[c] == 0) freq.erase(c);
        }
        best = max(best, right - left + 1);
    }

    cout << best;
    return 0;
}

Time Complexity: O(n) average
Space Complexity: O(k)

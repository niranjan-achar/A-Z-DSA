Question Number: 7
Problem Title: Smallest subarray with sum >= target
Problem Description:
Given an array of positive integers and a target, find the minimum length subarray with sum >= target.

Approach / Explanation:
1) Use a sliding window with two pointers.
2) Expand right pointer until sum >= target.
3) Shrink from left to minimize length while keeping sum >= target.
4) Track the minimum window length.
5) Positive numbers guarantee correctness.
6) If no window meets target, return -1.
7) Output the minimum length.

Brute Force Note:
Checking all subarrays costs O(n^2).

C++ Code:
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n; long long target;
    if (!(cin >> n) || n <= 0) return 0;
    vector<long long> a(n);
    for (int i = 0; i < n; ++i) cin >> a[i];
    cin >> target;

    int l = 0; long long sum = 0;
    int best = INT_MAX;
    for (int r = 0; r < n; ++r) {
        sum += a[r];
        while (l <= r && sum >= target) {
            best = min(best, r - l + 1);
            sum -= a[l++];
        }
    }

    if (best == INT_MAX) cout << -1; else cout << best;
    return 0;
}

Time Complexity: O(n)
Space Complexity: O(1)

Question Number: 7
Problem Title: Find the degree of a node in a graph
Problem Description:
Given an undirected graph and a node, output its degree.

Approach / Explanation:
1) Build adjacency list.
2) The degree of a node is the number of its neighbors.
3) For undirected graphs, each edge adds 1 degree to both ends.
4) Read the node index and print adj[node].size().
5) This is O(1) after building the list.
6) Works for disconnected graphs.
7) Output the degree.

Brute Force Note:
No brute force needed.

C++ Code:
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m, x; if (!(cin >> n >> m >> x) || n <= 0) return 0;
    --x;
    vector<vector<int>> adj(n);
    for (int i = 0; i < m; ++i) {
        int u, v; cin >> u >> v; --u; --v;
        adj[u].push_back(v);
        adj[v].push_back(u);
    }
    cout << (x >= 0 && x < n ? (int)adj[x].size() : 0);
    return 0;
}

Time Complexity: O(n + m)
Space Complexity: O(n + m)

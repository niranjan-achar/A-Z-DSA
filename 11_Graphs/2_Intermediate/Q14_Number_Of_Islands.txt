Question Number: 14
Problem Title: Number of islands in a grid
Problem Description:
Given a grid of 0/1, count the number of connected components of 1s.

Approach / Explanation:
1) Traverse each cell in the grid.
2) When a 1 is found, run DFS/BFS to mark its island.
3) Count each new DFS/BFS as one island.
4) Use 4-directional moves.
5) This ensures each cell is visited once.
6) O(n*m) time.
7) Output the island count.

Brute Force Note:
No brute force needed beyond traversal.

C++ Code:
#include <bits/stdc++.h>
using namespace std;

int n, m;
vector<string> grid;
int dr[4] = {1, -1, 0, 0};
int dc[4] = {0, 0, 1, -1};

void dfs(int r, int c) {
    grid[r][c] = '0';
    for (int k = 0; k < 4; ++k) {
        int nr = r + dr[k], nc = c + dc[k];
        if (nr < 0 || nc < 0 || nr >= n || nc >= m) continue;
        if (grid[nr][nc] == '1') dfs(nr, nc);
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    if (!(cin >> n >> m) || n <= 0 || m <= 0) return 0;
    grid.resize(n);
    for (int i = 0; i < n; ++i) cin >> grid[i];

    int cnt = 0;
    for (int i = 0; i < n; ++i)
        for (int j = 0; j < m; ++j)
            if (grid[i][j] == '1') { ++cnt; dfs(i, j); }

    cout << cnt;
    return 0;
}

Time Complexity: O(n*m)
Space Complexity: O(n*m)

Question Number: 3
Problem Title: Minimum Coin Change Problem
Problem Description:
Given coin denominations and an amount, find the minimum number of coins to make the amount.

Approach / Explanation:
1) Use dp[i] = minimum coins to make sum i.
2) Initialize dp[0]=0 and others to INF.
3) For each sum i, try all coins and relax dp[i].
4) dp[i] = min(dp[i], dp[i-coin] + 1).
5) This is unbounded coin change DP.
6) If dp[amount] is INF, no solution.
7) Output dp[amount] or -1.

Brute Force Note:
Trying all combinations is exponential.

C++ Code:
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, amount; if (!(cin >> n >> amount) || n < 0 || amount < 0) return 0;
    vector<int> coins(n);
    for (int i = 0; i < n; ++i) cin >> coins[i];

    const int INF = 1e9;
    vector<int> dp(amount + 1, INF);
    dp[0] = 0;
    for (int i = 1; i <= amount; ++i) {
        for (int c : coins) if (i - c >= 0 && dp[i - c] != INF) {
            dp[i] = min(dp[i], dp[i - c] + 1);
        }
    }

    cout << (dp[amount] == INF ? -1 : dp[amount]);
    return 0;
}

Time Complexity: O(n*amount)
Space Complexity: O(amount)

Question Number: 1
Problem Title: Fibonacci Sequence
Problem Description:
Given n, compute the nth Fibonacci number (0-indexed).

Approach / Explanation:
1) Use bottom-up DP with an array.
2) dp[0]=0 and dp[1]=1 are base cases.
3) For i from 2 to n, dp[i]=dp[i-1]+dp[i-2].
4) This reuses previously computed values.
5) Avoids exponential recursion.
6) Works for n >= 0.
7) Output dp[n].

Brute Force Note:
Naive recursion repeats subproblems and is exponential.

C++ Code:
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    long long n; if (!(cin >> n) || n < 0) return 0;
    if (n == 0) { cout << 0; return 0; }
    if (n == 1) { cout << 1; return 0; }
    vector<long long> dp(n + 1, 0);
    dp[0] = 0; dp[1] = 1;
    for (int i = 2; i <= n; ++i) dp[i] = dp[i-1] + dp[i-2];
    cout << dp[n];
    return 0;
}

Time Complexity: O(n)
Space Complexity: O(n)

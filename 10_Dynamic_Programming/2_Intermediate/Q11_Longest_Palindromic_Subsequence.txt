Question Number: 11
Problem Title: Longest Palindromic Subsequence
Problem Description:
Given a string, find the length of the longest palindromic subsequence.

Approach / Explanation:
1) Use dp[i][j] for the LPS length in s[i..j].
2) If s[i]==s[j], dp[i][j]=2+dp[i+1][j-1].
3) Else dp[i][j]=max(dp[i+1][j], dp[i][j-1]).
4) Fill dp by increasing substring length.
5) Base case: dp[i][i]=1.
6) This avoids exponential recursion.
7) Output dp[0][n-1].

Brute Force Note:
Checking all subsequences is exponential.

C++ Code:
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    string s; if (!(cin >> s)) return 0;
    int n = (int)s.size();
    if (n == 0) { cout << 0; return 0; }
    vector<vector<int>> dp(n, vector<int>(n, 0));
    for (int i = 0; i < n; ++i) dp[i][i] = 1;
    for (int len = 2; len <= n; ++len) {
        for (int i = 0; i + len - 1 < n; ++i) {
            int j = i + len - 1;
            if (s[i] == s[j]) dp[i][j] = 2 + (len == 2 ? 0 : dp[i+1][j-1]);
            else dp[i][j] = max(dp[i+1][j], dp[i][j-1]);
        }
    }
    cout << dp[0][n-1];
    return 0;
}

Time Complexity: O(n^2)
Space Complexity: O(n^2)

Question Number: 29
Problem Title: Palindrome Partitioning (Minimum Cuts)
Problem Description:
Given a string, find the minimum cuts to partition it into palindromes.

Approach / Explanation:
1) Precompute pal[i][j] for all substrings.
2) Use dp[i] = min cuts for prefix s[0..i].
3) If s[0..i] is palindrome, dp[i]=0.
4) Else dp[i]=min(dp[j-1]+1) for pal[j..i].
5) This uses optimal substructure.
6) Fill dp from left to right.
7) Output dp[n-1].

Brute Force Note:
Checking all partitions is exponential.

C++ Code:
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    string s; if (!(cin >> s)) return 0;
    int n = (int)s.size();
    vector<vector<char>> pal(n, vector<char>(n, 0));
    for (int i = n - 1; i >= 0; --i) {
        for (int j = i; j < n; ++j) {
            if (s[i] == s[j] && (j - i < 2 || pal[i+1][j-1])) pal[i][j] = 1;
        }
    }

    vector<int> dp(n, 0);
    for (int i = 0; i < n; ++i) {
        if (pal[0][i]) { dp[i] = 0; continue; }
        int best = i;
        for (int j = 1; j <= i; ++j) if (pal[j][i]) best = min(best, dp[j-1] + 1);
        dp[i] = best;
    }
    cout << (n == 0 ? 0 : dp[n-1]);
    return 0;
}

Time Complexity: O(n^2)
Space Complexity: O(n^2)

Question Number: 21
Problem Title: Regular Expression Matching
Problem Description:
Given a string s and pattern p with '.' and '*', determine if they match.

Approach / Explanation:
1) Use dp[i][j] for whether s[0..i-1] matches p[0..j-1].
2) dp[0][0]=true; handle patterns like a* for empty string.
3) If p[j-1] is normal or '.', match previous and dp[i-1][j-1].
4) If p[j-1] is '*', consider zero of previous or one more char.
5) dp[i][j] = dp[i][j-2] or (match and dp[i-1][j]).
6) Fill table bottom-up.
7) Output 1 if match, else 0.

Brute Force Note:
Recursive backtracking may be exponential.

C++ Code:
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    string s, p; if (!(cin >> s >> p)) return 0;
    int n = (int)s.size(), m = (int)p.size();
    vector<vector<char>> dp(n + 1, vector<char>(m + 1, 0));
    dp[0][0] = 1;
    for (int j = 2; j <= m; ++j) if (p[j-1] == '*') dp[0][j] = dp[0][j-2];

    for (int i = 1; i <= n; ++i) {
        for (int j = 1; j <= m; ++j) {
            if (p[j-1] == '.' || p[j-1] == s[i-1]) {
                dp[i][j] = dp[i-1][j-1];
            } else if (p[j-1] == '*') {
                dp[i][j] = dp[i][j-2];
                char prev = p[j-2];
                if (prev == '.' || prev == s[i-1]) dp[i][j] = dp[i][j] || dp[i-1][j];
            }
        }
    }
    cout << (dp[n][m] ? 1 : 0);
    return 0;
}

Time Complexity: O(n*m)
Space Complexity: O(n*m)

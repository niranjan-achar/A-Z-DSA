Question Number: 24
Problem Title: Maximum Sum Increasing Subsequence
Problem Description:
Given an array, find the maximum sum of an increasing subsequence.

Approach / Explanation:
1) Use dp[i] as max sum of increasing subsequence ending at i.
2) Initialize dp[i]=a[i].
3) For each i, check all j<i where a[j]<a[i].
4) dp[i]=max(dp[i], dp[j]+a[i]).
5) Track the maximum dp[i].
6) This is O(n^2) DP.
7) Output the maximum sum.

Brute Force Note:
Checking all subsequences is exponential.

C++ Code:
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n; if (!(cin >> n) || n < 0) return 0;
    vector<long long> a(n);
    for (int i = 0; i < n; ++i) cin >> a[i];

    vector<long long> dp(n, 0);
    long long best = 0;
    for (int i = 0; i < n; ++i) {
        dp[i] = a[i];
        for (int j = 0; j < i; ++j) if (a[j] < a[i]) dp[i] = max(dp[i], dp[j] + a[i]);
        best = max(best, dp[i]);
    }
    cout << best;
    return 0;
}

Time Complexity: O(n^2)
Space Complexity: O(n)

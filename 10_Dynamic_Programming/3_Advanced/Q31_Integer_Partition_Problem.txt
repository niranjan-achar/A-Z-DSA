Question Number: 31
Problem Title: Integer Partition Problem
Problem Description:
Given n, count the number of ways to write n as a sum of positive integers.

Approach / Explanation:
1) Use dp[i] = number of ways to form sum i.
2) Initialize dp[0]=1.
3) For each integer x from 1 to n, update dp forward.
4) dp[i] += dp[i-x] counts partitions using x.
5) Order by x avoids permutations.
6) This is coin-change style DP.
7) Output dp[n].

Brute Force Note:
Enumerating all partitions is exponential.

C++ Code:
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n; if (!(cin >> n) || n < 0) return 0;
    vector<long long> dp(n + 1, 0);
    dp[0] = 1;
    for (int x = 1; x <= n; ++x) {
        for (int i = x; i <= n; ++i) dp[i] += dp[i - x];
    }
    cout << dp[n];
    return 0;
}

Time Complexity: O(n^2)
Space Complexity: O(n)

Question Number: 9
Problem Title: Linear search in an array
Problem Description:
Given an array and a target value, find the index of the target or -1.

Approach / Explanation:
1) Scan the array from left to right.
2) If a[i] equals target, return its index.
3) If not found, return -1.
4) Works for unsorted arrays.
5) Single pass gives linear time.
6) No extra space required.
7) Output the index.

Brute Force Note:
Linear scan is the brute-force and optimal for unsorted arrays.

C++ Code:
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n; if (!(cin >> n) || n <= 0) return 0;
    vector<long long> a(n);
    for (int i = 0; i < n; ++i) cin >> a[i];
    long long target; cin >> target;

    int idx = -1;
    for (int i = 0; i < n; ++i) {
        if (a[i] == target) { idx = i; break; }
    }

    cout << idx;
    return 0;
}

Time Complexity: O(n)
Space Complexity: O(1)

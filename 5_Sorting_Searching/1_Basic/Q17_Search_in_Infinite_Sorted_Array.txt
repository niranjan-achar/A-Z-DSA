Question Number: 14
Problem Title: Find element in infinite sorted array (virtual binary search)
Problem Description:
Given a conceptually infinite sorted array and a target, find its index.

Approach / Explanation:
1) Exponentially expand the search range: [1,2,4,8...]
2) Stop when high is >= target or bounds exceed data.
3) Perform binary search in the found range.
4) This limits the search window quickly.
5) Works for large arrays with unknown bounds.
6) Time is O(log position).
7) Output index or -1.

Brute Force Note:
Linear scan is too slow for large indices.

C++ Code:
#include <bits/stdc++.h>
using namespace std;

// Simulated access: in practice, replace with API get(i)
int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n; long long target;
    if (!(cin >> n) || n <= 0) return 0;
    vector<long long> a(n);
    for (int i = 0; i < n; ++i) cin >> a[i];
    cin >> target;

    int l = 0, r = 1;
    while (r < n && a[r] < target) {
        l = r;
        r = r * 2;
    }
    if (r >= n) r = n - 1;

    int ans = -1;
    while (l <= r) {
        int m = l + (r - l) / 2;
        if (a[m] == target) { ans = m; break; }
        if (a[m] < target) l = m + 1; else r = m - 1;
    }

    cout << ans;
    return 0;
}

Time Complexity: O(log position)
Space Complexity: O(1)

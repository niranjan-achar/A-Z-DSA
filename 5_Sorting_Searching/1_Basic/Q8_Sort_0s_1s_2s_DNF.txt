Question Number: 8
Problem Title: Sort array of 0s, 1s and 2s (Dutch National Flag)
Problem Description:
Given an array containing only 0s, 1s, and 2s, sort it in linear time.

Approach / Explanation:
1) Use three pointers: low, mid, high.
2) Swap 0s to the front, 2s to the back, 1s stay in middle.
3) Move mid forward each step.
4) This is a single-pass in-place algorithm.
5) Linear time and constant space.
6) Works only for 0,1,2 values.
7) Output the sorted array.

Brute Force Note:
Counting 0s,1s,2s also works in two passes.

C++ Code:
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n; if (!(cin >> n) || n <= 0) return 0;
    vector<int> a(n);
    for (int i = 0; i < n; ++i) cin >> a[i];

    int low = 0, mid = 0, high = n - 1;
    while (mid <= high) {
        if (a[mid] == 0) swap(a[low++], a[mid++]);
        else if (a[mid] == 1) ++mid;
        else swap(a[mid], a[high--]);
    }

    for (int i = 0; i < n; ++i) {
        if (i) cout << " ";
        cout << a[i];
    }
    return 0;
}

Time Complexity: O(n)
Space Complexity: O(1)

Question Number: 13
Problem Title: Find floor and ceil of an element in sorted array
Problem Description:
Given a sorted array and a target, find floor (<=) and ceil (>=).

Approach / Explanation:
1) Use binary search to track candidate floor and ceil.
2) If a[mid] < target, update floor and move right.
3) If a[mid] > target, update ceil and move left.
4) If equal, both floor and ceil are target.
5) Works in O(log n).
6) Requires sorted array.
7) Output floor and ceil (or -1 if missing).

Brute Force Note:
Linear scan is O(n).

C++ Code:
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n; long long target;
    if (!(cin >> n) || n <= 0) return 0;
    vector<long long> a(n);
    for (int i = 0; i < n; ++i) cin >> a[i];
    cin >> target;

    long long floorVal = -1, ceilVal = -1;
    int l = 0, r = n - 1;
    while (l <= r) {
        int m = l + (r - l) / 2;
        if (a[m] == target) { floorVal = ceilVal = a[m]; break; }
        if (a[m] < target) { floorVal = a[m]; l = m + 1; }
        else { ceilVal = a[m]; r = m - 1; }
    }

    cout << floorVal << " " << ceilVal;
    return 0;
}

Time Complexity: O(log n)
Space Complexity: O(1)

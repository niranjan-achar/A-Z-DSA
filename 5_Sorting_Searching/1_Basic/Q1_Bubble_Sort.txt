Question Number: 1
Problem Title: Implement Bubble Sort
Problem Description:
Given an array, sort it using Bubble Sort.

Approach / Explanation:
1) Repeatedly compare adjacent elements and swap if out of order.
2) After each pass, the largest element bubbles to the end.
3) Continue for n passes or stop early if no swaps occur.
4) This is stable and easy to implement.
5) Best for small inputs or learning.
6) In-place, no extra memory.
7) Output the sorted array.

Brute Force Note:
Bubble sort itself is a brute-force O(n^2) method.

C++ Code:
#include <bits/stdc++.h>
using namespace std;

void bubbleSort(vector<long long>& a) {
    int n = (int)a.size();
    for (int i = 0; i < n; ++i) {
        bool swapped = false;
        for (int j = 0; j + 1 < n - i; ++j) {
            if (a[j] > a[j + 1]) {
                swap(a[j], a[j + 1]);
                swapped = true;
            }
        }
        if (!swapped) break;
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n; if (!(cin >> n) || n <= 0) return 0;
    vector<long long> a(n);
    for (int i = 0; i < n; ++i) cin >> a[i];

    bubbleSort(a);

    for (int i = 0; i < n; ++i) {
        if (i) cout << " ";
        cout << a[i];
    }
    return 0;
}

Time Complexity: O(n^2)
Space Complexity: O(1)

Question Number: 16
Problem Title: Sort array based on absolute difference with a given number
Problem Description:
Given an array and a number x, sort elements by increasing |a[i] - x|.

Approach / Explanation:
1) Use std::stable_sort with a custom comparator.
2) Compare absolute differences from x.
3) Stable sort keeps original order for equal differences.
4) This is simple and clear.
5) Works for negative numbers too.
6) Time dominated by sorting.
7) Output the sorted array.

Brute Force Note:
Repeatedly selecting closest elements costs O(n^2).

C++ Code:
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n; long long x;
    if (!(cin >> n) || n <= 0) return 0;
    vector<long long> a(n);
    for (int i = 0; i < n; ++i) cin >> a[i];
    cin >> x;

    stable_sort(a.begin(), a.end(), [&](long long p, long long q) {
        return llabs(p - x) < llabs(q - x);
    });

    for (int i = 0; i < n; ++i) {
        if (i) cout << " ";
        cout << a[i];
    }
    return 0;
}

Time Complexity: O(n log n)
Space Complexity: O(1) extra

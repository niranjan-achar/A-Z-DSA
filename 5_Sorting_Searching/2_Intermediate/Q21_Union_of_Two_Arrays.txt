Question Number: 21
Problem Title: Find union of two arrays
Problem Description:
Given two arrays, output the union of elements (unique values).

Approach / Explanation:
1) Insert all elements into a hash set.
2) The set keeps only unique values.
3) Output all elements from the set.
4) This works for unsorted arrays.
5) Average O(1) insertion.
6) Order is arbitrary unless specified.
7) Output the union or -1 if empty.

Brute Force Note:
Checking uniqueness with nested loops costs O(n^2).

C++ Code:
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m; if (!(cin >> n >> m) || n < 0 || m < 0) return 0;
    unordered_set<long long> st;
    for (int i = 0; i < n; ++i) { long long x; cin >> x; st.insert(x); }
    for (int i = 0; i < m; ++i) { long long x; cin >> x; st.insert(x); }

    if (st.empty()) { cout << -1; return 0; }
    bool first = true;
    for (long long x : st) {
        if (!first) cout << " ";
        cout << x; first = false;
    }
    return 0;
}

Time Complexity: O(n+m) average
Space Complexity: O(n+m)

Question Number: 23
Problem Title: Count number of swaps required to sort the array
Problem Description:
Given an array, compute the minimum number of swaps to sort it.

Approach / Explanation:
1) Pair each element with its original index.
2) Sort pairs by value to find target positions.
3) The permutation decomposes into cycles.
4) Each cycle of length L needs L-1 swaps.
5) Sum swaps across cycles.
6) This gives the minimum number of swaps.
7) Output the count.

Brute Force Note:
Simulating swaps by selection costs O(n^2).

C++ Code:
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n; if (!(cin >> n) || n <= 0) return 0;
    vector<pair<long long, int>> v(n);
    for (int i = 0; i < n; ++i) { cin >> v[i].first; v[i].second = i; }

    sort(v.begin(), v.end());
    vector<bool> vis(n, false);
    long long swaps = 0;

    for (int i = 0; i < n; ++i) {
        if (vis[i] || v[i].second == i) continue;
        int j = i, cycleLen = 0;
        while (!vis[j]) {
            vis[j] = true;
            j = v[j].second;
            ++cycleLen;
        }
        if (cycleLen > 1) swaps += (cycleLen - 1);
    }

    cout << swaps;
    return 0;
}

Time Complexity: O(n log n)
Space Complexity: O(n)

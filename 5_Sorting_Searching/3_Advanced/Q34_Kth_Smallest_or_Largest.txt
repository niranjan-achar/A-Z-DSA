Question Number: 29
Problem Title: Kth smallest or largest element using sorting
Problem Description:
Given an array and k, find the k-th smallest and k-th largest elements.

Approach / Explanation:
1) Sort the array in ascending order.
2) The k-th smallest is at index k-1.
3) The k-th largest is at index n-k.
4) Sorting gives a simple and reliable solution.
5) Works for duplicates as well.
6) Ensure k is valid.
7) Output k-th smallest and k-th largest.

Brute Force Note:
Using nth_element gives O(n) average without full sort.

C++ Code:
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, k; if (!(cin >> n) || n <= 0) return 0;
    vector<long long> a(n);
    for (int i = 0; i < n; ++i) cin >> a[i];
    cin >> k;
    if (k < 1 || k > n) return 0;

    sort(a.begin(), a.end());
    cout << a[k - 1] << " " << a[n - k];
    return 0;
}

Time Complexity: O(n log n)
Space Complexity: O(1) extra

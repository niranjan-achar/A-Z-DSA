Question Number: 28
Problem Title: Find missing number in range 1 to n (binary search or XOR)
Problem Description:
Given numbers from 1 to n with one missing, find the missing number.

Approach / Explanation:
1) Use XOR of 1..n and XOR of array elements.
2) XOR cancels paired values and leaves the missing number.
3) This uses constant space.
4) Works in linear time.
5) No sorting required.
6) Output the missing value.
7) Use long long for safety.

Brute Force Note:
Sorting and scanning costs O(n log n).

C++ Code:
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    long long n; if (!(cin >> n) || n <= 1) return 0;
    long long xr = 0;
    for (long long i = 1; i <= n; ++i) xr ^= i;
    for (long long i = 0; i < n - 1; ++i) { long long x; cin >> x; xr ^= x; }

    cout << xr;
    return 0;
}

Time Complexity: O(n)
Space Complexity: O(1)

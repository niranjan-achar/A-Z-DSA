Question Number: 16
Problem Title: Calculate nCr (Combination)
Problem Description:
Given n and r, compute nCr using DP.

Approach / Explanation:
1) Use Pascal's triangle with dp[i][j].
2) Base cases: dp[i][0]=dp[i][i]=1.
3) dp[i][j]=dp[i-1][j-1]+dp[i-1][j].
4) Build up to n.
5) Works for moderate n.
6) O(n*r) time.
7) Output dp[n][r].

Brute Force Note:
Using factorials may overflow quickly.

C++ Code:
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, r; if (!(cin >> n >> r) || n < 0 || r < 0 || r > n) return 0;
    vector<vector<long long>> dp(n + 1, vector<long long>(r + 1, 0));
    for (int i = 0; i <= n; ++i) {
        int lim = min(i, r);
        dp[i][0] = 1;
        for (int j = 1; j <= lim; ++j) {
            if (j == i) dp[i][j] = 1;
            else dp[i][j] = dp[i-1][j-1] + dp[i-1][j];
        }
    }
    cout << dp[n][r];
    return 0;
}

Time Complexity: O(n*r)
Space Complexity: O(n*r)

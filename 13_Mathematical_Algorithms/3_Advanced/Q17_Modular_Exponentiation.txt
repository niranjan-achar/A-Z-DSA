Question Number: 17
Problem Title: Modular Exponentiation
Problem Description:
Given a, b, and mod, compute a^b mod mod.

Approach / Explanation:
1) Use fast exponentiation by squaring.
2) If b is odd, multiply result by a.
3) Square a and halve b each step.
4) Take mod at each multiplication.
5) O(log b) time.
6) Works for large exponents.
7) Output the result.

Brute Force Note:
Multiplying a b times is too slow.

C++ Code:
#include <bits/stdc++.h>
using namespace std;

long long modpow(long long a, long long b, long long mod) {
    long long res = 1 % mod;
    a %= mod;
    while (b > 0) {
        if (b & 1) res = (__int128)res * a % mod;
        a = (__int128)a * a % mod;
        b >>= 1;
    }
    return res;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    long long a, b, mod; if (!(cin >> a >> b >> mod) || mod == 0) return 0;
    cout << modpow(a, b, mod);
    return 0;
}

Time Complexity: O(log b)
Space Complexity: O(1)

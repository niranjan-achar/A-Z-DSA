Question Number: 21
Problem Title: Prime factorization
Problem Description:
Given n, output its prime factorization.

Approach / Explanation:
1) Divide by 2 while possible.
2) For odd i from 3 to sqrt(n), divide while possible.
3) If remaining n > 1, it is a prime factor.
4) Output factors with multiplicity.
5) O(sqrt(n)) time.
6) Works for 64-bit n.
7) Output factors in ascending order.

Brute Force Note:
Checking all divisors is slower.

C++ Code:
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    long long n; if (!(cin >> n) || n < 0) return 0;
    if (n <= 1) return 0;
    bool first = true;
    while (n % 2 == 0) { if (!first) cout << " "; cout << 2; first = false; n /= 2; }
    for (long long i = 3; i * i <= n; i += 2) {
        while (n % i == 0) { if (!first) cout << " "; cout << i; first = false; n /= i; }
    }
    if (n > 1) { if (!first) cout << " "; cout << n; }
    return 0;
}

Time Complexity: O(sqrt(n))
Space Complexity: O(1)

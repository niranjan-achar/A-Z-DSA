Question Number: 7
Problem Title: Check if a number is an Armstrong number
Problem Description:
Given n, determine if it is an Armstrong number.

Approach / Explanation:
1) Count the number of digits k.
2) Sum each digit raised to k.
3) Compare sum with original number.
4) If equal, it is an Armstrong number.
5) Works for non-negative integers.
6) O(d) time.
7) Output 1 if Armstrong, else 0.

Brute Force Note:
No brute force needed.

C++ Code:
#include <bits/stdc++.h>
using namespace std;

long long ipow(long long a, int b) {
    long long res = 1;
    while (b--) res *= a;
    return res;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    long long n; if (!(cin >> n) || n < 0) return 0;
    long long t = n, sum = 0;
    int k = 0;
    if (t == 0) k = 1;
    while (t > 0) { ++k; t /= 10; }
    t = n;
    while (t > 0) { sum += ipow(t % 10, k); t /= 10; }
    cout << (sum == n ? 1 : 0);
    return 0;
}

Time Complexity: O(d)
Space Complexity: O(1)

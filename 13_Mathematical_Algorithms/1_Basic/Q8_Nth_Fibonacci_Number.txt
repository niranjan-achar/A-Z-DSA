Question Number: 8
Problem Title: Find the nth Fibonacci number
Problem Description:
Given n, compute the nth Fibonacci number (0-indexed).

Approach / Explanation:
1) Use iterative DP with two variables.
2) Start with a=0, b=1.
3) Repeatedly update a and b for n steps.
4) For n=0, return 0.
5) This is O(n) time and O(1) space.
6) Avoids recursion overhead.
7) Output the nth Fibonacci.

Brute Force Note:
Naive recursion is exponential.

C++ Code:
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    long long n; if (!(cin >> n) || n < 0) return 0;
    if (n == 0) { cout << 0; return 0; }
    long long a = 0, b = 1;
    for (long long i = 2; i <= n; ++i) {
        long long c = a + b;
        a = b; b = c;
    }
    cout << b;
    return 0;
}

Time Complexity: O(n)
Space Complexity: O(1)

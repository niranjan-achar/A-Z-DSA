Question Number: 4
Problem Title: Find the LCM of two numbers
Problem Description:
Given two integers, compute their least common multiple.

Approach / Explanation:
1) Use relation: lcm(a,b) = |a*b| / gcd(a,b).
2) Compute gcd using Euclidean algorithm.
3) Avoid overflow by dividing first when possible.
4) If either number is zero, lcm is 0.
5) O(log min(a,b)) time.
6) Output the LCM.
7) Works for 64-bit inputs.

Brute Force Note:
Checking multiples is slow.

C++ Code:
#include <bits/stdc++.h>
using namespace std;

long long gcdll(long long a, long long b) {
    while (b != 0) { long long t = a % b; a = b; b = t; }
    return a;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    long long a, b; if (!(cin >> a >> b)) return 0;
    if (a == 0 || b == 0) { cout << 0; return 0; }
    long long g = gcdll(llabs(a), llabs(b));
    long long l = llabs(a / g * b);
    cout << l;
    return 0;
}

Time Complexity: O(log min(a,b))
Space Complexity: O(1)

Question Number: 1
Problem Title: Prime number check
Problem Description:
Given a number n, determine if it is prime.

Approach / Explanation:
1) Handle n <= 1 as not prime.
2) Check divisibility from 2 to sqrt(n).
3) If any divisor found, not prime.
4) Otherwise prime.
5) This is O(sqrt(n)).
6) Works for n up to 64-bit.
7) Output 1 if prime, else 0.

Brute Force Note:
Checking divisibility up to n is slower.

C++ Code:
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    long long n; if (!(cin >> n)) return 0;
    if (n <= 1) { cout << 0; return 0; }
    for (long long i = 2; i * i <= n; ++i) if (n % i == 0) { cout << 0; return 0; }
    cout << 1;
    return 0;
}

Time Complexity: O(sqrt(n))
Space Complexity: O(1)

Question Number: 22
Problem Title: Building Bridges
Problem Description:
Given pairs of north and south bank coordinates, build maximum non-crossing bridges.

Approach / Explanation:
1) Sort pairs by north coordinate, then by south.
2) The problem reduces to LIS on south coordinates.
3) Compute LIS length using patience method.
4) The LIS length is the maximum number of non-crossing bridges.
5) Sorting ensures order on one side.
6) O(n log n) time.
7) Output the maximum bridges.

Brute Force Note:
Trying all subsets is exponential.

C++ Code:
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n; if (!(cin >> n) || n <= 0) return 0;
    vector<pair<int,int>> a(n);
    for (int i = 0; i < n; ++i) cin >> a[i].first >> a[i].second;
    sort(a.begin(), a.end());

    vector<int> lis;
    for (auto &p : a) {
        int x = p.second;
        auto it = lower_bound(lis.begin(), lis.end(), x);
        if (it == lis.end()) lis.push_back(x);
        else *it = x;
    }

    cout << (int)lis.size();
    return 0;
}

Time Complexity: O(n log n)
Space Complexity: O(n)

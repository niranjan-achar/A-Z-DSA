Question Number: 25
Problem Title: Rearrange string so no adjacent characters are the same
Problem Description:
Given a string, rearrange characters so that no two adjacent characters are equal.

Approach / Explanation:
1) Count frequency of each character.
2) Use a max-heap of (count, char).
3) Pop the most frequent char, append it, and hold it as previous.
4) Push previous back if its count remains.
5) If heap empties while previous still has count, not possible.
6) Greedy always uses the most frequent available char.
7) Output the rearranged string or -1.

Brute Force Note:
Checking all permutations is factorial time.

C++ Code:
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    string s; if (!(cin >> s)) return 0;
    unordered_map<char,int> freq;
    for (char c : s) ++freq[c];

    priority_queue<pair<int,char>> pq;
    for (auto &kv : freq) pq.push({kv.second, kv.first});

    string res;
    pair<int,char> prev = {0, '#'};
    while (!pq.empty()) {
        auto cur = pq.top(); pq.pop();
        res.push_back(cur.second);
        cur.first--;
        if (prev.first > 0) pq.push(prev);
        prev = cur;
    }

    if ((int)res.size() != (int)s.size()) cout << -1; else cout << res;
    return 0;
}

Time Complexity: O(n log k)
Space Complexity: O(k)

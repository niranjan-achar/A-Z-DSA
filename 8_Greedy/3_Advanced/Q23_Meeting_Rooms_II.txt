Question Number: 23
Problem Title: Meeting Rooms II
Problem Description:
Given meeting intervals, find the minimum number of rooms required.

Approach / Explanation:
1) Sort meetings by start time.
2) Use a min-heap for end times of ongoing meetings.
3) If the earliest ending meeting ends before next starts, reuse its room.
4) Otherwise, allocate a new room.
5) Heap size gives rooms needed.
6) O(n log n) time.
7) Output the minimum rooms.

Brute Force Note:
Checking all overlaps pairwise is O(n^2).

C++ Code:
#include <bits/stdc++.h>
using namespace std;

struct Interval { int s, e; };

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n; if (!(cin >> n) || n <= 0) return 0;
    vector<Interval> a(n);
    for (int i = 0; i < n; ++i) cin >> a[i].s >> a[i].e;
    sort(a.begin(), a.end(), [](const Interval& x, const Interval& y){ return x.s < y.s; });

    priority_queue<int, vector<int>, greater<int>> pq;
    for (const auto& it : a) {
        if (!pq.empty() && pq.top() <= it.s) pq.pop();
        pq.push(it.e);
    }
    cout << (int)pq.size();
    return 0;
}

Time Complexity: O(n log n)
Space Complexity: O(n)

Question Number: 18
Problem Title: Candy Distribution
Problem Description:
Given ratings of children, distribute candies so higher-rated kids get more than neighbors.

Approach / Explanation:
1) Give each child 1 candy initially.
2) Left to right: if rating increases, add 1 more than left neighbor.
3) Right to left: if rating increases, ensure right side condition.
4) Sum all candies after adjustments.
5) This greedy two-pass ensures minimal total.
6) O(n) time and O(n) space.
7) Output the minimum candies required.

Brute Force Note:
Trying all distributions is exponential.

C++ Code:
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n; if (!(cin >> n) || n <= 0) return 0;
    vector<int> r(n), c(n, 1);
    for (int i = 0; i < n; ++i) cin >> r[i];

    for (int i = 1; i < n; ++i) if (r[i] > r[i-1]) c[i] = c[i-1] + 1;
    for (int i = n-2; i >= 0; --i) if (r[i] > r[i+1]) c[i] = max(c[i], c[i+1] + 1);

    long long sum = 0;
    for (int x : c) sum += x;
    cout << sum;
    return 0;
}

Time Complexity: O(n)
Space Complexity: O(n)

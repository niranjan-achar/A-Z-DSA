Question Number: 14
Problem Title: K-th Largest Sum Contiguous Subarray
Problem Description:
Given an array and k, find the k-th largest sum among all contiguous subarrays.

Approach / Explanation:
1) Generate all subarray sums using prefix sums.
2) Maintain a min-heap of size k.
3) Push each sum, pop if size exceeds k.
4) Heap top is the k-th largest sum.
5) Total subarrays are n*(n+1)/2.
6) O(n^2 log k) time.
7) Output the k-th largest sum.

Brute Force Note:
Sorting all sums costs O(n^2 log n).

C++ Code:
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n; long long k; if (!(cin >> n >> k) || n <= 0 || k <= 0) return 0;
    vector<long long> a(n+1, 0);
    for (int i = 1; i <= n; ++i) { cin >> a[i]; a[i] += a[i-1]; }

    priority_queue<long long, vector<long long>, greater<long long>> pq;
    for (int i = 1; i <= n; ++i) {
        for (int j = 0; j < i; ++j) {
            long long sum = a[i] - a[j];
            if ((long long)pq.size() < k) pq.push(sum);
            else if (sum > pq.top()) { pq.pop(); pq.push(sum); }
        }
    }

    if ((long long)pq.size() < k) cout << -1; else cout << pq.top();
    return 0;
}

Time Complexity: O(n^2 log k)
Space Complexity: O(k)

Question Number: 16
Problem Title: Minimum number of coins to make change
Problem Description:
Given coin denominations and an amount, find minimum coins using greedy choice.

Approach / Explanation:
1) Sort coins in descending order.
2) Take as many as possible from the largest coin.
3) Reduce remaining amount and continue.
4) If amount reaches zero, solution found.
5) Greedy is optimal for canonical coin systems.
6) O(n log n) time for sorting.
7) Output the minimum number of coins or -1.

Brute Force Note:
Trying all combinations is exponential.

C++ Code:
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n; long long amount; if (!(cin >> n >> amount) || n <= 0) return 0;
    vector<long long> coins(n);
    for (int i = 0; i < n; ++i) cin >> coins[i];
    sort(coins.rbegin(), coins.rend());

    long long cnt = 0;
    for (long long c : coins) {
        if (amount <= 0) break;
        if (c <= 0) continue;
        long long take = amount / c;
        cnt += take;
        amount -= take * c;
    }

    cout << (amount == 0 ? cnt : -1);
    return 0;
}

Time Complexity: O(n log n)
Space Complexity: O(1) extra

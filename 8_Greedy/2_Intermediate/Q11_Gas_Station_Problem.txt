Question Number: 11
Problem Title: Gas Station Problem
Problem Description:
Given gas and cost arrays, find a starting index to complete the circuit once.

Approach / Explanation:
1) If total gas < total cost, no solution.
2) Track current balance while scanning left to right.
3) When balance drops below zero, reset start to next index.
4) Accumulate total gas-cost to validate existence.
5) Greedy reset works because deficits cannot be fixed earlier.
6) Single pass solution.
7) Output the starting index or -1.

Brute Force Note:
Trying each start is O(n^2).

C++ Code:
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n; if (!(cin >> n) || n <= 0) return 0;
    vector<long long> gas(n), cost(n);
    for (int i = 0; i < n; ++i) cin >> gas[i];
    for (int i = 0; i < n; ++i) cin >> cost[i];

    long long total = 0, cur = 0;
    int start = 0;
    for (int i = 0; i < n; ++i) {
        long long diff = gas[i] - cost[i];
        total += diff;
        cur += diff;
        if (cur < 0) { start = i + 1; cur = 0; }
    }
    cout << (total >= 0 ? start : -1);
    return 0;
}

Time Complexity: O(n)
Space Complexity: O(1)

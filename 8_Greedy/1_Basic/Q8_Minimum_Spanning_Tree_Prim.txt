Question Number: 8
Problem Title: Minimum Spanning Tree (Prim's algorithm)
Problem Description:
Given a connected weighted graph, find the total weight of a minimum spanning tree.

Approach / Explanation:
1) Start from any node and push its edges to a min-heap.
2) Repeatedly pick the minimum weight edge that connects a new node.
3) Mark the node as visited and add its edges.
4) Continue until all nodes are included.
5) Prim's greedy choice builds an MST.
6) O(E log V) time with heap.
7) Output the total MST weight.

Brute Force Note:
Checking all spanning trees is infeasible.

C++ Code:
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m; if (!(cin >> n >> m) || n <= 0) return 0;
    vector<vector<pair<int,int>>> g(n);
    for (int i = 0; i < m; ++i) {
        int u, v, w; cin >> u >> v >> w;
        --u; --v;
        g[u].push_back({v, w});
        g[v].push_back({u, w});
    }

    vector<int> vis(n, 0);
    priority_queue<pair<int,int>, vector<pair<int,int>>, greater<pair<int,int>>> pq;
    pq.push({0, 0});
    long long total = 0;
    while (!pq.empty()) {
        auto [w, u] = pq.top(); pq.pop();
        if (vis[u]) continue;
        vis[u] = 1; total += w;
        for (auto [v, wt] : g[u]) if (!vis[v]) pq.push({wt, v});
    }
    cout << total;
    return 0;
}

Time Complexity: O(E log V)
Space Complexity: O(V + E)

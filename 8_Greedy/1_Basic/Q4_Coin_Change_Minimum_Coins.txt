Question Number: 4
Problem Title: Coin Change (Minimum coins needed)
Problem Description:
Given coin denominations and an amount, find the minimum number of coins using greedy choice.

Approach / Explanation:
1) Sort coins in descending order.
2) Take as many coins as possible from the largest denomination.
3) Reduce the amount and continue with smaller coins.
4) If amount becomes zero, solution is found.
5) Greedy is optimal for canonical coin systems.
6) If amount cannot be made, return -1.
7) Output the minimum number of coins.

Brute Force Note:
Trying all combinations is exponential.

C++ Code:
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n; long long amount; if (!(cin >> n >> amount) || n <= 0) return 0;
    vector<long long> coins(n);
    for (int i = 0; i < n; ++i) cin >> coins[i];
    sort(coins.rbegin(), coins.rend());

    long long cnt = 0;
    for (long long c : coins) {
        if (amount <= 0) break;
        if (c <= 0) continue;
        long long take = amount / c;
        cnt += take;
        amount -= take * c;
    }

    cout << (amount == 0 ? cnt : -1);
    return 0;
}

Time Complexity: O(n log n)
Space Complexity: O(1) extra

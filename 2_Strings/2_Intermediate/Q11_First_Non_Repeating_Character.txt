Question Number: 11
Problem Title: First non-repeating character in a string
Problem Description:
Given a string, find the first character that occurs exactly once.

Approach / Explanation:
1) Count frequencies using an array of size 256.
2) Scan the string again from left to right.
3) The first character with frequency 1 is the answer.
4) Two passes preserve original order.
5) Works for ASCII inputs.
6) If none exist, output -1.
7) Output the character.

Brute Force Note:
Nested loops to check each character cost O(n^2).

C++ Code:
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    string s; if (!getline(cin, s)) return 0;
    vector<int> freq(256, 0);
    for (unsigned char c : s) ++freq[c];

    char ans = 0;
    bool found = false;
    for (unsigned char c : s) {
        if (freq[c] == 1) { ans = (char)c; found = true; break; }
    }

    if (!found) cout << -1; else cout << ans;
    return 0;
}

Time Complexity: O(n)
Space Complexity: O(1)

Question Number: 20
Problem Title: Check if a string is a valid shuffle of two strings
Problem Description:
Given strings a, b, and c, check if c is a valid shuffle of a and b.

Approach / Explanation:
1) If lengths don't add up, return false.
2) Use two pointers i for a and j for b.
3) Traverse c; if c[k] matches a[i], advance i else if matches b[j], advance j.
4) If c[k] matches neither, it's invalid.
5) At end, both i and j must reach the ends.
6) This checks order-preserving shuffle.
7) Output 1 if valid, 0 otherwise.

Brute Force Note:
DP can check all interleavings but is heavier for this rule.

C++ Code:
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    string a, b, c;
    if (!getline(cin, a)) return 0;
    if (!getline(cin, b)) return 0;
    if (!getline(cin, c)) return 0;

    if (a.size() + b.size() != c.size()) { cout << 0; return 0; }

    size_t i = 0, j = 0;
    for (char ch : c) {
        if (i < a.size() && ch == a[i]) ++i;
        else if (j < b.size() && ch == b[j]) ++j;
        else { cout << 0; return 0; }
    }

    cout << 1;
    return 0;
}

Time Complexity: O(n)
Space Complexity: O(1)

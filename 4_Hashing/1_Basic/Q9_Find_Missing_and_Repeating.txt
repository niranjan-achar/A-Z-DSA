Question Number: 9
Problem Title: Find missing and repeating number
Problem Description:
Given an array of size n containing numbers 1..n with one missing and one repeating, find both.

Approach / Explanation:
1) Count frequencies using a hash map.
2) The number with count 2 is repeating.
3) The number with count 0 is missing.
4) Scan from 1 to n to identify both.
5) This is simple and easy to verify.
6) Uses extra space but linear time.
7) Output repeating then missing.

Brute Force Note:
Sorting and scanning also works but is O(n log n).

C++ Code:
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n; if (!(cin >> n) || n <= 0) return 0;
    vector<int> freq(n + 1, 0);
    for (int i = 0; i < n; ++i) { int x; cin >> x; if (x>=1 && x<=n) ++freq[x]; }

    int missing = -1, repeating = -1;
    for (int i = 1; i <= n; ++i) {
        if (freq[i] == 0) missing = i;
        else if (freq[i] == 2) repeating = i;
    }

    cout << repeating << " " << missing;
    return 0;
}

Time Complexity: O(n)
Space Complexity: O(n)

Question Number: 2
Problem Title: Find the first non-repeating element
Problem Description:
Given an array, find the first element that occurs exactly once.

Approach / Explanation:
1) Count frequencies using a hash map.
2) Scan the array again from left to right.
3) The first element with count 1 is the answer.
4) Two passes preserve the original order.
5) Works for any integer values.
6) If none exist, output -1.
7) Output the element.

Brute Force Note:
Nested loops to count each element cost O(n^2).

C++ Code:
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n; if (!(cin >> n) || n <= 0) return 0;
    vector<long long> a(n);
    unordered_map<long long, int> freq;
    for (int i = 0; i < n; ++i) { cin >> a[i]; ++freq[a[i]]; }

    long long ans = LLONG_MIN;
    for (long long x : a) {
        if (freq[x] == 1) { ans = x; break; }
    }

    if (ans == LLONG_MIN) cout << -1; else cout << ans;
    return 0;
}

Time Complexity: O(n) average
Space Complexity: O(n)

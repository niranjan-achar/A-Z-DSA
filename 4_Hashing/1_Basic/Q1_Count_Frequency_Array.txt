Question Number: 1
Problem Title: Count frequency of elements in an array
Problem Description:
Given an array, count the frequency of each distinct element.

Approach / Explanation:
1) Use a hash map to store element -> count.
2) Scan the array and increment the count for each element.
3) Hashing gives average O(1) insert/lookup.
4) This avoids nested loops.
5) Works for negative values and large ranges.
6) Output each element with its frequency.
7) Order can be arbitrary unless specified.

Brute Force Note:
Counting each element by scanning the array costs O(n^2).

C++ Code:
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n; if (!(cin >> n) || n <= 0) return 0;
    unordered_map<long long, int> freq;
    for (int i = 0; i < n; ++i) {
        long long x; cin >> x;
        ++freq[x];
    }

    for (const auto& kv : freq) {
        cout << kv.first << " " << kv.second << "\n";
    }
    return 0;
}

Time Complexity: O(n) average
Space Complexity: O(n)

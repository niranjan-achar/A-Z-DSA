Question Number: 10
Problem Title: Check if array has a pair with a given sum
Problem Description:
Given an array and a target sum, check if any pair sums to the target.

Approach / Explanation:
1) Use a hash set of seen values.
2) For each element x, check if (target - x) exists in the set.
3) If yes, a pair is found.
4) Otherwise, insert x into the set.
5) Single pass gives linear time.
6) Works with negative values.
7) Output 1 if pair exists, 0 otherwise.

Brute Force Note:
Checking all pairs costs O(n^2).

C++ Code:
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n; long long target;
    if (!(cin >> n) || n <= 0) return 0;
    vector<long long> a(n);
    for (int i = 0; i < n; ++i) cin >> a[i];
    cin >> target;

    unordered_set<long long> seen;
    for (long long x : a) {
        if (seen.count(target - x)) { cout << 1; return 0; }
        seen.insert(x);
    }

    cout << 0;
    return 0;
}

Time Complexity: O(n) average
Space Complexity: O(n)

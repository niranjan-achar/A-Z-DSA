Question Number: 11
Problem Title: Longest substring without repeating characters
Problem Description:
Given a string, find the length of the longest substring with all distinct characters.

Approach / Explanation:
1) Use sliding window with last seen index for each character.
2) When a repeat appears, move left to last_seen + 1.
3) Update maximum window length each step.
4) This keeps the window valid.
5) Single pass yields linear time.
6) Works for ASCII input.
7) Output the maximum length.

Brute Force Note:
Checking all substrings costs O(n^2).

C++ Code:
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    string s; if (!getline(cin >> ws, s)) return 0;
    vector<int> last(256, -1);
    int left = 0, best = 0;
    for (int i = 0; i < (int)s.size(); ++i) {
        unsigned char c = s[i];
        if (last[c] >= left) left = last[c] + 1;
        last[c] = i;
        best = max(best, i - left + 1);
    }

    cout << best;
    return 0;
}

Time Complexity: O(n)
Space Complexity: O(1)

Question Number: 22
Problem Title: Longest subarray with equal 0s and 1s
Problem Description:
Given a binary array, find the length of the longest subarray with equal number of 0s and 1s.

Approach / Explanation:
1) Replace 0 with -1 and 1 with +1.
2) The problem reduces to longest subarray with sum 0.
3) Store first index of each prefix sum.
4) If prefix sum repeats, compute length.
5) Track the maximum length.
6) Initialize prefix sum 0 at index -1.
7) Output the maximum length.

Brute Force Note:
Checking all subarrays costs O(n^2).

C++ Code:
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n; if (!(cin >> n) || n <= 0) return 0;
    vector<int> a(n);
    for (int i = 0; i < n; ++i) cin >> a[i];

    unordered_map<int, int> first;
    first[0] = -1;
    int prefix = 0, best = 0;
    for (int i = 0; i < n; ++i) {
        prefix += (a[i] == 0 ? -1 : 1);
        if (first.count(prefix)) best = max(best, i - first[prefix]);
        else first[prefix] = i;
    }

    cout << best;
    return 0;
}

Time Complexity: O(n) average
Space Complexity: O(n)

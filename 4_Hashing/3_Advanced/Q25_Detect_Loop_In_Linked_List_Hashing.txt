Question Number: 25
Problem Title: Detect loop in a linked list using hashing
Problem Description:
Given a linked list, determine if it contains a cycle using hashing.

Approach / Explanation:
1) Traverse the list and store node addresses in a hash set.
2) If a node is seen again, a cycle exists.
3) This is simple and easy to implement.
4) Uses extra memory for visited nodes.
5) Works for any list length.
6) Linear time on average.
7) Output 1 if loop exists, 0 otherwise.

Brute Force Note:
Floyd's cycle detection uses O(1) space.

C++ Code:
#include <bits/stdc++.h>
using namespace std;

struct Node {
    int val;
    Node* next;
    Node(int v) : val(v), next(nullptr) {}
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    // Input format is not standardized for linked lists in text.
    // This code shows the detection logic using hashing.
    // Build your list and set head accordingly.
    Node* head = nullptr;

    unordered_set<Node*> seen;
    Node* cur = head;
    bool hasLoop = false;
    while (cur) {
        if (seen.count(cur)) { hasLoop = true; break; }
        seen.insert(cur);
        cur = cur->next;
    }

    cout << (hasLoop ? 1 : 0);
    return 0;
}

Time Complexity: O(n) average
Space Complexity: O(n)

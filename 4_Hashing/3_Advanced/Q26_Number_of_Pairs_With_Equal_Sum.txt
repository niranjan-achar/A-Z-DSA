Question Number: 26
Problem Title: Find the number of pairs with equal sum
Problem Description:
Given an array, count the number of unordered pairs of index-pairs with equal sum.

Approach / Explanation:
1) Compute sums of all pairs (i, j) with i < j.
2) Use a hash map to count how many times each sum appears.
3) For each sum with frequency f, add f*(f-1)/2 to the answer.
4) This counts pairs of pairs having the same sum.
5) Works for any integers.
6) Time is O(n^2) due to pair enumeration.
7) Output the total count.

Brute Force Note:
Checking all pair-of-pairs explicitly costs O(n^4).

C++ Code:
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n; if (!(cin >> n) || n <= 1) return 0;
    vector<long long> a(n);
    for (int i = 0; i < n; ++i) cin >> a[i];

    unordered_map<long long, long long> freq;
    for (int i = 0; i < n; ++i) {
        for (int j = i + 1; j < n; ++j) {
            ++freq[a[i] + a[j]];
        }
    }

    long long ans = 0;
    for (const auto& kv : freq) {
        long long f = kv.second;
        ans += f * (f - 1) / 2;
    }

    cout << ans;
    return 0;
}

Time Complexity: O(n^2)
Space Complexity: O(n^2)

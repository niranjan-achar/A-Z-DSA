Question Number: 27
Problem Title: Minimum operations to make array elements equal
Problem Description:
Given an array, find the minimum number of operations to make all elements equal.

Approach / Explanation:
1) The optimal target is the median of the array.
2) Sort the array and pick the middle element.
3) Sum absolute differences from the median.
4) This minimizes total moves in L1 distance.
5) Works for any integers.
6) Sorting dominates time complexity.
7) Output the minimum operations.

Brute Force Note:
Trying all targets is O(n^2).

C++ Code:
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n; if (!(cin >> n) || n <= 0) return 0;
    vector<long long> a(n);
    for (int i = 0; i < n; ++i) cin >> a[i];

    sort(a.begin(), a.end());
    long long median = a[n / 2];
    long long ops = 0;
    for (long long x : a) ops += llabs(x - median);

    cout << ops;
    return 0;
}

Time Complexity: O(n log n)
Space Complexity: O(1)

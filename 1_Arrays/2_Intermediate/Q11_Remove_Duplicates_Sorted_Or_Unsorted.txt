Question Number: 11
Problem Title: Remove duplicates from sorted/unsorted array
Problem Description:
Given an array, remove duplicates and output the array of unique elements.

Approach / Explanation:
1) For unsorted arrays, use a hash set to track seen values.
2) Scan the array and keep the first occurrence of each value.
3) This preserves the original order of first appearances.
4) For sorted arrays, a two-pointer in-place solution exists.
5) Hashing gives average O(n) time for any input order.
6) The output size equals the count of distinct elements.
7) Print the unique elements.

Brute Force Note:
Nested loops to check uniqueness cost O(n^2).

C++ Code:
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n; if (!(cin >> n) || n <= 0) return 0;
    vector<long long> a(n);
    for (int i = 0; i < n; ++i) cin >> a[i];

    unordered_set<long long> seen;
    vector<long long> uniqueVals;
    uniqueVals.reserve(n);

    for (long long x : a) {
        if (seen.insert(x).second) {
            uniqueVals.push_back(x);
        }
    }

    for (int i = 0; i < (int)uniqueVals.size(); ++i) {
        if (i) cout << " ";
        cout << uniqueVals[i];
    }
    return 0;
}

Time Complexity: O(n) average
Space Complexity: O(n)

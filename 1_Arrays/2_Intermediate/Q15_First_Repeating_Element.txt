Question Number: 15
Problem Title: Find the first repeating element
Problem Description:
Given an array, find the first element that repeats (smallest index among repeating elements).

Approach / Explanation:
1) Traverse the array from right to left.
2) Maintain a hash set of seen elements.
3) If an element is already in the set, it is repeating.
4) Update answer to this element and continue left to find earlier repeats.
5) Right-to-left ensures the final answer has the smallest index.
6) Hashing gives average O(1) insert and lookup.
7) Output the element or -1 if none repeat.

Brute Force Note:
Checking all pairs is O(n^2).

C++ Code:
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n; if (!(cin >> n) || n <= 0) return 0;
    vector<long long> a(n);
    for (int i = 0; i < n; ++i) cin >> a[i];

    unordered_set<long long> seen;
    long long ans = LLONG_MIN;
    for (int i = n - 1; i >= 0; --i) {
        if (seen.count(a[i])) ans = a[i];
        else seen.insert(a[i]);
    }

    if (ans == LLONG_MIN) cout << -1;
    else cout << ans;
    return 0;
}

Time Complexity: O(n) average
Space Complexity: O(n)

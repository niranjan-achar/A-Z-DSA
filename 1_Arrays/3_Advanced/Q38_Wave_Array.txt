Question Number: 38
Problem Title: Wave array (sort in wave form)
Problem Description:
Arrange the array so a[0] >= a[1] <= a[2] >= a[3] ... (wave form).

Approach / Explanation:
1) Sort the array in non-decreasing order.
2) Swap adjacent elements in pairs: (0,1), (2,3), ...
3) This ensures the wave condition for all positions.
4) Sorting handles duplicates safely.
5) Pairwise swapping is linear after sorting.
6) Output the wave-formed array.
7) Works for any numeric array.

Brute Force Note:
Trying all permutations is infeasible.

C++ Code:
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n; if (!(cin >> n) || n <= 0) return 0;
    vector<long long> a(n);
    for (int i = 0; i < n; ++i) cin >> a[i];

    sort(a.begin(), a.end());
    for (int i = 0; i + 1 < n; i += 2) {
        swap(a[i], a[i + 1]);
    }

    for (int i = 0; i < n; ++i) {
        if (i) cout << " ";
        cout << a[i];
    }
    return 0;
}

Time Complexity: O(n log n)
Space Complexity: O(1)

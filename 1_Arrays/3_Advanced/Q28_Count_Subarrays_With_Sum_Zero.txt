Question Number: 28
Problem Title: Count subarrays with sum zero
Problem Description:
Given an array, count the number of subarrays whose sum is zero.

Approach / Explanation:
1) Use prefix sums; if two prefix sums are equal, the subarray sum is zero.
2) Maintain a map of prefix sum frequencies.
3) For each prefix sum, add its previous frequency to the answer.
4) Initialize freq[0] = 1 to count subarrays starting at index 0.
5) Hash map gives average O(1) updates.
6) This handles negative values correctly.
7) Output the total count.

Brute Force Note:
Checking all subarrays is O(n^2).

C++ Code:
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n; if (!(cin >> n) || n <= 0) return 0;
    unordered_map<long long, long long> freq;
    long long prefix = 0, ans = 0;
    freq[0] = 1;

    for (int i = 0; i < n; ++i) {
        long long x; cin >> x;
        prefix += x;
        if (freq.count(prefix)) ans += freq[prefix];
        ++freq[prefix];
    }

    cout << ans;
    return 0;
}

Time Complexity: O(n) average
Space Complexity: O(n)

Question Number: 25
Problem Title: Check for majority element (appears > n/2 times)
Problem Description:
Find if an element appears more than n/2 times and return it, otherwise -1.

Approach / Explanation:
1) Use Boyer-Moore voting to find a candidate.
2) Keep a count that increases for same values and decreases otherwise.
3) The remaining candidate can be the majority.
4) Verify the candidate by counting its frequency.
5) This gives linear time and constant space.
6) Works even when no majority exists.
7) Output the majority element or -1.

Brute Force Note:
Sorting and checking middle element is O(n log n).

C++ Code:
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n; if (!(cin >> n) || n <= 0) return 0;
    vector<long long> a(n);
    for (int i = 0; i < n; ++i) cin >> a[i];

    long long cand = 0; int count = 0;
    for (long long x : a) {
        if (count == 0) { cand = x; count = 1; }
        else if (x == cand) ++count;
        else --count;
    }

    int freq = 0;
    for (long long x : a) if (x == cand) ++freq;

    if (freq > n / 2) cout << cand; else cout << -1;
    return 0;
}

Time Complexity: O(n)
Space Complexity: O(1)

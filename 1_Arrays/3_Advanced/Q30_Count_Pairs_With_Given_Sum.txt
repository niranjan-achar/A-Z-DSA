Question Number: 30
Problem Title: Count pairs with a given sum
Problem Description:
Given an array and a target sum, count pairs (i, j) with i < j and a[i] + a[j] = target.

Approach / Explanation:
1) Use a hash map to store counts of seen numbers.
2) For each element x, look for (target - x) among seen elements.
3) Add the count of complement to the answer.
4) Then increment count of x.
5) This counts pairs in a single pass.
6) Works for negative numbers and duplicates.
7) Output the total count.

Brute Force Note:
Checking all pairs costs O(n^2).

C++ Code:
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n; long long target;
    if (!(cin >> n) || n <= 0) return 0;
    vector<long long> a(n);
    for (int i = 0; i < n; ++i) cin >> a[i];
    cin >> target;

    unordered_map<long long, long long> cnt;
    long long ans = 0;
    for (long long x : a) {
        long long need = target - x;
        if (cnt.count(need)) ans += cnt[need];
        ++cnt[x];
    }

    cout << ans;
    return 0;
}

Time Complexity: O(n) average
Space Complexity: O(n)

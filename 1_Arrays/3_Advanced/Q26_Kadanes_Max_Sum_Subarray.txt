Question Number: 26
Problem Title: Kadane's Algorithm - Maximum sum subarray
Problem Description:
Find the maximum possible sum of a contiguous subarray.

Approach / Explanation:
1) Maintain current sum ending at each position.
2) Either extend the previous subarray or start fresh at current element.
3) Track the global maximum seen so far.
4) This avoids checking all subarrays.
5) Works for negative-only arrays by choosing the largest element.
6) Single pass yields optimal time.
7) Output the maximum sum.

Brute Force Note:
Checking all subarrays costs O(n^2) or O(n^3).

C++ Code:
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n; if (!(cin >> n) || n <= 0) return 0;
    long long best = LLONG_MIN, cur = 0;
    for (int i = 0; i < n; ++i) {
        long long x; cin >> x;
        cur = max(x, cur + x);
        best = max(best, cur);
    }

    cout << best;
    return 0;
}

Time Complexity: O(n)
Space Complexity: O(1)

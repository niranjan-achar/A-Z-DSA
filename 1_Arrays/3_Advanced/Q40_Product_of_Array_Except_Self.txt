Question Number: 40
Problem Title: Product of array except self
Problem Description:
Given an array, return an array where each index has the product of all elements except itself.

Approach / Explanation:
1) Compute prefix products and suffix products.
2) The result at i is prefix[i-1] * suffix[i+1].
3) Use one result array to store prefix, then multiply by suffix on the fly.
4) This avoids division and handles zeros correctly.
5) Two passes give linear time.
6) Uses O(n) space for result.
7) Output the resulting array.

Brute Force Note:
Computing product for each index separately costs O(n^2).

C++ Code:
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n; if (!(cin >> n) || n <= 0) return 0;
    vector<long long> a(n), res(n, 1);
    for (int i = 0; i < n; ++i) cin >> a[i];

    long long prefix = 1;
    for (int i = 0; i < n; ++i) {
        res[i] = prefix;
        prefix *= a[i];
    }
    long long suffix = 1;
    for (int i = n - 1; i >= 0; --i) {
        res[i] *= suffix;
        suffix *= a[i];
    }

    for (int i = 0; i < n; ++i) {
        if (i) cout << " ";
        cout << res[i];
    }
    return 0;
}

Time Complexity: O(n)
Space Complexity: O(n)

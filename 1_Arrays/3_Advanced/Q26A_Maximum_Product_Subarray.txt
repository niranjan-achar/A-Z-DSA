Question Number: 26A
Problem Title: Maximum product subarray
Problem Description:
Find the maximum product of a contiguous subarray.

Approach / Explanation:
1) Track both maximum and minimum products ending at each index.
2) A negative number can flip max and min, so swap when x < 0.
3) Update maxEnd = max(x, maxEnd * x) and minEnd similarly.
4) Maintain a global max product across all positions.
5) This handles zeros and negative values correctly.
6) Single pass provides linear time.
7) Output the maximum product.

Brute Force Note:
Enumerating all subarrays is O(n^2) and can overflow easily.

C++ Code:
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n; if (!(cin >> n) || n <= 0) return 0;
    long long maxEnd = 1, minEnd = 1, best = LLONG_MIN;
    for (int i = 0; i < n; ++i) {
        long long x; cin >> x;
        if (x < 0) swap(maxEnd, minEnd);
        maxEnd = max(x, maxEnd * x);
        minEnd = min(x, minEnd * x);
        best = max(best, maxEnd);
    }

    cout << best;
    return 0;
}

Time Complexity: O(n)
Space Complexity: O(1)

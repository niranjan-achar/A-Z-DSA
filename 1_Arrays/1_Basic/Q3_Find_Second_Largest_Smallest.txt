Question Number: 3
Problem Title: Find the second largest and second smallest element
Problem Description:
Given an array, find the second largest and second smallest distinct elements.

Approach / Explanation:
1) Track four values: smallest, second smallest, largest, second largest.
2) Update these values in one pass, skipping duplicates.
3) Distinctness matters, so equal values do not shift second values.
4) Initialize using large/small sentinels.
5) If distinct second values do not exist, report accordingly.
6) This avoids sorting and keeps O(1) space.
7) Output second smallest then second largest.

Brute Force Note:
Sorting and picking neighbors works but costs O(n log n).

C++ Code:
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    if (!(cin >> n) || n <= 0) return 0;
    vector<long long> a(n);
    for (int i = 0; i < n; ++i) cin >> a[i];

    long long INF = LLONG_MAX;
    long long min1 = INF, min2 = INF;
    long long max1 = LLONG_MIN, max2 = LLONG_MIN;

    for (long long x : a) {
        if (x < min1) { min2 = min1; min1 = x; }
        else if (x > min1 && x < min2) { min2 = x; }

        if (x > max1) { max2 = max1; max1 = x; }
        else if (x < max1 && x > max2) { max2 = x; }
    }

    if (min2 == INF || max2 == LLONG_MIN) {
        cout << "Not Found";
    } else {
        cout << min2 << " " << max2;
    }

    return 0;
}

Time Complexity: O(n)
Space Complexity: O(1)

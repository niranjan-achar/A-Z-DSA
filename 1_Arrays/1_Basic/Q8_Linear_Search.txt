Question Number: 8
Problem Title: Search for an element (linear search)
Problem Description:
Given an array and a target, find the index of the target or report not found.

Approach / Explanation:
1) Scan the array from left to right.
2) If a[i] equals target, output the index and stop.
3) If no match is found, output -1.
4) This works for unsorted arrays.
5) Single pass is optimal in the worst case.
6) Use 0-based index in output.
7) Handles duplicates by returning the first occurrence.

Brute Force Note:
Linear scan is the brute force and optimal for unsorted arrays.

C++ Code:
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n; if (!(cin >> n) || n <= 0) return 0;
    vector<long long> a(n);
    for (int i = 0; i < n; ++i) cin >> a[i];
    long long target; cin >> target;

    int idx = -1;
    for (int i = 0; i < n; ++i) {
        if (a[i] == target) { idx = i; break; }
    }

    cout << idx;
    return 0;
}

Time Complexity: O(n)
Space Complexity: O(1)

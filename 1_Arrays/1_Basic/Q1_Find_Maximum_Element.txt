Question Number: 1
Problem Title: Find the maximum element in an array
Problem Description:
Given an array of integers, find the maximum element.

Approach / Explanation:
1) Initialize ans with the first element.
2) Scan the array once and update ans when a larger value appears.
3) This uses a single pass and keeps only the current best value.
4) Works for negative numbers and mixed signs.
5) If the array has one element, that element is the max.
6) No extra data structures are required.
7) Output the final ans.

Brute Force Note:
Sorting to take the last element is possible but slower.

C++ Code:
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    if (!(cin >> n) || n <= 0) return 0;
    vector<long long> a(n);
    for (int i = 0; i < n; ++i) cin >> a[i];

    long long ans = a[0];
    for (int i = 1; i < n; ++i) {
        if (a[i] > ans) ans = a[i];
    }

    cout << ans;
    return 0;
}

Time Complexity: O(n)
Space Complexity: O(1)

Question Number: 28
Problem Title: Maximum of all subarrays of size k
Problem Description:
Given an array and k, output the maximum in each window.

Approach / Explanation:
1) Use a deque of indices with decreasing values.
2) Remove indices out of the window.
3) Remove smaller values from the back.
4) Front index gives current maximum.
5) Each element processed once.
6) O(n) time and O(k) space.
7) Output max for each window.

Brute Force Note:
Scanning each window costs O(nk).

C++ Code:
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, k; if (!(cin >> n) || n <= 0) return 0;
    vector<long long> a(n);
    for (int i = 0; i < n; ++i) cin >> a[i];
    cin >> k;
    if (k <= 0 || k > n) return 0;

    deque<int> dq;
    for (int i = 0; i < n; ++i) {
        while (!dq.empty() && dq.front() <= i - k) dq.pop_front();
        while (!dq.empty() && a[dq.back()] <= a[i]) dq.pop_back();
        dq.push_back(i);
        if (i >= k - 1) {
            if (i > k - 1) cout << " ";
            cout << a[dq.front()];
        }
    }

    return 0;
}

Time Complexity: O(n)
Space Complexity: O(k)

Question Number: 13
Problem Title: Celebrity Problem
Problem Description:
Given a matrix knows[i][j], find if there is a celebrity (known by all, knows none).

Approach / Explanation:
1) Use two pointers i and j to eliminate non-celebrities.
2) If i knows j, i cannot be celebrity; else j cannot be celebrity.
3) After reduction, verify the candidate.
4) Candidate must know nobody and be known by everyone.
5) This gives O(n) eliminations plus O(n) verification.
6) Total O(n) time.
7) Output index or -1.

Brute Force Note:
Checking every pair costs O(n^2).

C++ Code:
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n; if (!(cin >> n) || n <= 0) return 0;
    vector<vector<int>> knows(n, vector<int>(n));
    for (int i = 0; i < n; ++i) for (int j = 0; j < n; ++j) cin >> knows[i][j];

    int i = 0, j = n - 1;
    while (i < j) {
        if (knows[i][j]) ++i; else --j;
    }
    int cand = i;

    for (int k = 0; k < n; ++k) {
        if (k == cand) continue;
        if (knows[cand][k] || !knows[k][cand]) { cout << -1; return 0; }
    }

    cout << cand;
    return 0;
}

Time Complexity: O(n)
Space Complexity: O(1) extra

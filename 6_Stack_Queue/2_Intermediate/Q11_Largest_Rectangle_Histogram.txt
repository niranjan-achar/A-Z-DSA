Question Number: 11
Problem Title: Largest Rectangle in Histogram
Problem Description:
Given bar heights, find the area of the largest rectangle.

Approach / Explanation:
1) Use a monotonic stack of indices with increasing heights.
2) When a lower height appears, pop and compute areas.
3) For each popped bar, width is current index minus new top minus 1.
4) Process all bars and then clear the stack.
5) This is linear time.
6) Uses stack for indices.
7) Output the maximum area.

Brute Force Note:
Checking all rectangles costs O(n^2).

C++ Code:
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n; if (!(cin >> n) || n <= 0) return 0;
    vector<long long> h(n);
    for (int i = 0; i < n; ++i) cin >> h[i];

    stack<int> st;
    long long best = 0;
    for (int i = 0; i <= n; ++i) {
        long long cur = (i == n ? 0 : h[i]);
        while (!st.empty() && cur < h[st.top()]) {
            int top = st.top(); st.pop();
            long long height = h[top];
            int left = st.empty() ? -1 : st.top();
            long long width = i - left - 1;
            best = max(best, height * width);
        }
        st.push(i);
    }

    cout << best;
    return 0;
}

Time Complexity: O(n)
Space Complexity: O(n)

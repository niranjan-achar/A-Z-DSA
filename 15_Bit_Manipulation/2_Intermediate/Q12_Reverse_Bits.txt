Problem 12: Reverse Bits of a Number

Description:
Reverse the bits of a 32-bit unsigned integer.

Approach:
Extract bits from LSB and build new number by shifting left.

Brute Force Note:
Convert to binary string, reverse, convert back: O(32) time.

C++ Code:
```cpp
#include <iostream>
using namespace std;

uint32_t reverseBits(uint32_t n) {
    uint32_t result = 0;
    
    for (int i = 0; i < 32; i++) {
        result <<= 1;
        if (n & 1)
            result |= 1;
        n >>= 1;
    }
    
    return result;
}

int main() {
    uint32_t num = 43261596;  // 00000010100101000001111010011100
    
    uint32_t reversed = reverseBits(num);
    cout << "Original: " << num << endl;
    cout << "Reversed: " << reversed << endl;
    
    return 0;
}
```

Time Complexity: O(32) = O(1) - Fixed 32 iterations
Space Complexity: O(1) - Constant space

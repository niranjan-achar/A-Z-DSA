Problem 2: Set ith Bit

Description:
Set the ith bit of a number to 1.

Approach:
Use bitwise OR operation: num | (1 << i). Create a mask with 1 at ith position and OR it.

Brute Force Note:
Convert to binary, modify, convert back: O(log n) time.

C++ Code:
```cpp
#include <iostream>
using namespace std;

int setBit(int num, int i) {
    return num | (1 << i);
}

int main() {
    int num = 5;  // Binary: 101
    int i = 1;
    
    cout << "Original: " << num << " (Binary: ";
    for (int j = 7; j >= 0; j--)
        cout << ((num >> j) & 1);
    cout << ")" << endl;
    
    int result = setBit(num, i);
    cout << "After setting bit " << i << ": " << result << " (Binary: ";
    for (int j = 7; j >= 0; j--)
        cout << ((result >> j) & 1);
    cout << ")" << endl;
    
    return 0;
}
```

Time Complexity: O(1) - Constant time bit operation
Space Complexity: O(1) - Constant space

Problem 5: Clear Rightmost Set Bit

Description:
Clear the rightmost set bit of a number.

Approach:
Use: num & (num - 1). This clears the rightmost set bit efficiently.

Brute Force Note:
Find rightmost set bit position and clear: O(log n) time.

C++ Code:
```cpp
#include <iostream>
using namespace std;

int clearRightmostSetBit(int num) {
    return num & (num - 1);
}

int main() {
    int num = 12;  // Binary: 1100
    
    cout << "Original: " << num << " (Binary: ";
    for (int j = 7; j >= 0; j--)
        cout << ((num >> j) & 1);
    cout << ")" << endl;
    
    int result = clearRightmostSetBit(num);
    cout << "After clearing rightmost set bit: " << result << " (Binary: ";
    for (int j = 7; j >= 0; j--)
        cout << ((result >> j) & 1);
    cout << ")" << endl;
    
    return 0;
}
```

Time Complexity: O(1) - Constant time bit operation
Space Complexity: O(1) - Constant space

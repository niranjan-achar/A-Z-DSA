Problem 7: Check if Number is Power of 2

Description:
Check if a number is a power of 2.

Approach:
Use: (num > 0) && ((num & (num - 1)) == 0). Power of 2 has only one set bit.

Brute Force Note:
Divide by 2 repeatedly: O(log n) time.

C++ Code:
```cpp
#include <iostream>
using namespace std;

bool isPowerOfTwo(int num) {
    return (num > 0) && ((num & (num - 1)) == 0);
}

int main() {
    int numbers[] = {1, 2, 3, 4, 5, 8, 16, 20, 32, 64};
    
    for (int num : numbers) {
        cout << num << " is power of 2: " 
             << (isPowerOfTwo(num) ? "Yes" : "No") << endl;
    }
    
    return 0;
}
```

Time Complexity: O(1) - Constant time bit operation
Space Complexity: O(1) - Constant space

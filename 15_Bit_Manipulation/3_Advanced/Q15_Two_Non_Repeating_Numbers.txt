Problem 15: Find Two Non-Repeating Numbers

Description:
Find two numbers that appear once in an array where all others appear twice. Optimize space.

Approach:
Use bit manipulation with bit partitioning. XOR to find difference, use difference bit to partition.

Brute Force Note:
Hash map: O(n) time, O(n) space.

C++ Code:
```cpp
#include <iostream>
#include <vector>
using namespace std;

pair<int, int> findTwoNumbers(vector<int>& arr) {
    int xorResult = 0;
    for (int num : arr)
        xorResult ^= num;
    
    // Find rightmost set bit in xorResult
    int rightmostBit = xorResult & (-xorResult);
    
    int num1 = 0, num2 = 0;
    
    for (int num : arr) {
        if (num & rightmostBit)
            num1 ^= num;
        else
            num2 ^= num;
    }
    
    return {num1, num2};
}

int main() {
    vector<int> arr = {1, 2, 1, 3, 2, 5};
    auto result = findTwoNumbers(arr);
    
    cout << "Two non-repeating numbers: " << result.first << " and " 
         << result.second << endl;
    
    return 0;
}
```

Time Complexity: O(n) - Multiple passes through array
Space Complexity: O(1) - Constant space

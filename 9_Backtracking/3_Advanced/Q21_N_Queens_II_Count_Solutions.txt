Question Number: 21
Problem Title: N-Queens II (count solutions)
Problem Description:
Given n, count the number of ways to place n queens on an n x n board.

Approach / Explanation:
1) Use backtracking row by row.
2) Track used columns and diagonals for O(1) checks.
3) Place a queen if safe and recurse.
4) When row reaches n, increment count.
5) Backtrack by removing the queen and marks.
6) This explores all valid placements.
7) Output the total count.

Brute Force Note:
Trying all n^n placements is infeasible.

C++ Code:
#include <bits/stdc++.h>
using namespace std;

long long countSol = 0;
vector<int> col, d1, d2;

void dfs(int r, int n) {
    if (r == n) { ++countSol; return; }
    for (int c = 0; c < n; ++c) {
        if (col[c] || d1[r - c + n - 1] || d2[r + c]) continue;
        col[c] = d1[r - c + n - 1] = d2[r + c] = 1;
        dfs(r + 1, n);
        col[c] = d1[r - c + n - 1] = d2[r + c] = 0;
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n; if (!(cin >> n) || n <= 0) return 0;
    col.assign(n, 0);
    d1.assign(2*n - 1, 0);
    d2.assign(2*n - 1, 0);
    dfs(0, n);
    cout << countSol;
    return 0;
}

Time Complexity: Exponential
Space Complexity: O(n)

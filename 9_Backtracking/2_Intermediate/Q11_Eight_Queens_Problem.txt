Question Number: 11
Problem Title: Solve the 8 Queens problem
Problem Description:
Place 8 queens on a chessboard so that none attack each other.

Approach / Explanation:
1) Use backtracking row by row for an 8x8 board.
2) Track used columns and diagonals for O(1) checks.
3) Place a queen if the column and diagonals are free.
4) Recurse to the next row.
5) Count solutions when all rows are filled.
6) This explores only valid placements.
7) Output the number of solutions.

Brute Force Note:
Trying all 8^8 placements is infeasible.

C++ Code:
#include <bits/stdc++.h>
using namespace std;

long long countSol = 0;
vector<int> col(8, 0), d1(15, 0), d2(15, 0);

void dfs(int r) {
    if (r == 8) { ++countSol; return; }
    for (int c = 0; c < 8; ++c) {
        if (col[c] || d1[r - c + 7] || d2[r + c]) continue;
        col[c] = d1[r - c + 7] = d2[r + c] = 1;
        dfs(r + 1);
        col[c] = d1[r - c + 7] = d2[r + c] = 0;
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    dfs(0);
    cout << countSol;
    return 0;
}

Time Complexity: Exponential
Space Complexity: O(1) extra

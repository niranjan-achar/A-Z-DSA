Question Number: 20
Problem Title: Detect loop in a doubly linked list
Problem Description:
Given a doubly linked list, determine if it contains a cycle.

Approach / Explanation:
1) Use two pointers (slow/fast) like Floyd's algorithm.
2) Move slow by 1 and fast by 2 via next pointers.
3) If they meet, a cycle exists.
4) If fast reaches null, no cycle.
5) Works for doubly linked lists as well.
6) O(n) time and O(1) space.
7) Output 1 if loop exists, 0 otherwise.

Brute Force Note:
Using a hash set of visited nodes uses O(n) space.

C++ Code:
#include <bits/stdc++.h>
using namespace std;

struct Node { long long val; Node* prev; Node* next; Node(long long v): val(v), prev(nullptr), next(nullptr) {} };

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    Node* head = nullptr;
    Node* slow = head; Node* fast = head;
    bool hasCycle = false;
    while (fast && fast->next) {
        slow = slow->next; fast = fast->next->next;
        if (slow == fast) { hasCycle = true; break; }
    }

    cout << (hasCycle ? 1 : 0);
    return 0;
}

Time Complexity: O(n)
Space Complexity: O(1)

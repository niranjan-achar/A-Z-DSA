Question Number: 27
Problem Title: Split a circular linked list into two halves
Problem Description:
Given a circular linked list, split it into two circular halves.

Approach / Explanation:
1) Use slow/fast pointers to find middle.
2) For even nodes, move fast one extra step.
3) Set head1 as original head and head2 as slow->next.
4) Break and rewire to form two circles.
5) O(n) time and O(1) extra space.
6) Works for odd and even lengths.
7) Output the two lists.

Brute Force Note:
Converting to linear list then splitting is unnecessary.

C++ Code:
#include <bits/stdc++.h>
using namespace std;

struct Node { long long val; Node* next; Node(long long v): val(v), next(nullptr) {} };

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    // Input format for circular list splitting is not standardized.
    // This snippet shows the split logic.
    Node* head = nullptr;
    if (!head) return 0;

    Node* slow = head; Node* fast = head;
    while (fast->next != head && fast->next->next != head) {
        slow = slow->next;
        fast = fast->next->next;
    }
    if (fast->next->next == head) fast = fast->next;

    Node* head1 = head;
    Node* head2 = slow->next;

    fast->next = head2;
    slow->next = head1;

    // Output head1 and head2 in any expected format.
    (void)head1; (void)head2;
    return 0;
}

Time Complexity: O(n)
Space Complexity: O(1)

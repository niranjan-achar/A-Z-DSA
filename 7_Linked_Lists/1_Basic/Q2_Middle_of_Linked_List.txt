Question Number: 2
Problem Title: Find the middle element of the linked list
Problem Description:
Given a singly linked list, find its middle node.

Approach / Explanation:
1) Use two pointers: slow and fast.
2) Slow moves 1 step, fast moves 2 steps.
3) When fast reaches end, slow is at middle.
4) For even length, returns the second middle.
5) Single pass and O(1) space.
6) Works for any list length.
7) Output the middle value.

Brute Force Note:
Computing length then traversing again is O(n) but two passes.

C++ Code:
#include <bits/stdc++.h>
using namespace std;

struct Node {
    long long val; Node* next; Node(long long v): val(v), next(nullptr) {}
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n; if (!(cin >> n) || n <= 0) return 0;
    Node* head = nullptr; Node* tail = nullptr;
    for (int i = 0; i < n; ++i) {
        long long x; cin >> x;
        Node* node = new Node(x);
        if (!head) head = tail = node;
        else { tail->next = node; tail = node; }
    }

    Node* slow = head; Node* fast = head;
    while (fast && fast->next) { slow = slow->next; fast = fast->next->next; }

    cout << slow->val;
    return 0;
}

Time Complexity: O(n)
Space Complexity: O(1)
